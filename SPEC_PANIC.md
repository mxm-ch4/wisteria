# SPEC_PANIC.md — кнопка паники

> По прямой команде владельца, вместе с остальными функциями (до установщика и релиза). Одна сессия, Opus, коммит и пуш после зелёного шлюза, отчёт не больше полстраницы.
> Правила: A5.1 §8 (всё через меню), STEALTH, SPEC_PASSIVE «ноль лишних пакетов».

## Что делает паника
Один бинд (настраивается в Client → Privacy, по умолчанию не назначен) и кнопка в меню. Срабатывает мгновенно, за один тик, без анимаций:

| Действие | Детали |
|---|---|
| Выключить все модули | Включая активные. Состояние до паники запоминается, чтобы вернуть одной кнопкой «Восстановить» |
| Закрыть экраны клиента | ClickGUI, редактор HUD, свои диалоги |
| Спрятать весь визуал | HUD, ESP, чамсы, BaseFinder, водяной знак, тосты, подсказки. Главное меню остаётся в обычном виде |
| Остановить фоновое | Сканирование чанков, предсказание Xray, медиа-помощник, отложенные задачи |
| Подавить уведомления и локальный вывод в чат | Пока паника активна |
| Отпустить управление | Сбросить зажатые клавиши и состояния модулей (бег, наведение, авто-действия), чтобы игрок не продолжал действие |
| Опция «Выйти из мира» | Выключена по умолчанию: штатное отключение от сервера |
| Опция «Закрыть игру» | Выключена по умолчанию: штатный выход через игру |

## Что не делает
- Не удаляет и не прячет файлы на диске, не стирает логи, не удаляет jar, не меняет атрибуты файлов, не чистит историю системы. Причины: Windows держит jar занятым, пока игра запущена; самоудаляющееся и скрывающее поведение выглядит как вредоносное и вызывает антивирус; а против проверок на серверах, где они требуются, это обход, которого мы не строим.
- Не лезет в сеть и ничего не отправляет серверу. Тест: паника не создаёт исходящих пакетов (кроме опционального штатного отключения).

## Отдельно: очистка своих данных (по желанию владельца)
Кнопка «Очистить мои данные» в Client → Privacy с подтверждением: удаляет **только содержимое папки данных клиента** (секреты, прокси-пароли в `.env`, сиды, кэши BaseFinder, профили). Папка и мод остаются. Нужна для случая, когда владелец отдаёт компьютер или хочет сбросить секреты. Всегда после явного подтверждения, никогда по сигналу и без бинда.

## Тесты
- Модульные: возврат состояния кнопкой «Восстановить», сброс удерживаемых действий, запрет локального вывода при активной панике.
- Игровой: включены ESP, HUD, Xray, BaseFinder, медиа; паника; кадр без единого элемента клиента; аудит сети без лишних пакетов; «Восстановить» возвращает набор модулей.
- «Кликнуть всё»: новые контролы в реестре.
- Очистка данных: тест на временной папке данных, проверка, что удалено только внутри неё.

## Готово, когда
Паника гасит весь видимый клиент за один тик и возвращает его обратно, очистка данных работает по подтверждению, шлюз на OpenGL и Vulkan зелёный, аудит сети чистый.
