# Grim-матрица

Результаты живых тестов модулей против GrimAC. Заполняет владелец на своём стенде (SPEC_AMENDMENT_1 §3),
позже — Grim Lab автоматически (SPEC_AMENDMENT_2 §6). По этой таблице правятся дефолтные пресеты.

**Пока пусто: ни один модуль не проверен против Grim.**

## Стенд

| | |
|---|---|
| Версия GrimAC (`/grim version`) | _заполнить_ |
| Сервер | _заполнить: ядро и версия_ |
| Клиент | _заполнить_ |
| ViaVersion между клиентом и сервером | _да / нет_ |
| N — сколько минут без флагов и кика считаем «чисто» | _заполнить_ |

Зелёный результат здесь значит «не хуже этого стенда», а не «безопасно на 2b2t»: там другая версия сервера,
трансляция через ViaVersion и свой конфиг.

## Результаты

| Модуль | Режим/пресет | Версия клиента/сервера | Сработавшая проверка Grim | VL | Настройка, которая лечит | Итог |
|---|---|---|---|---|---|---|

Правила:

- Один модуль — минимум одна строка на дефолтном пресете. Агрессивные режимы — отдельными строками.
- Перед тестом включить алерты: `/grim alerts`, при необходимости `/grim verbose`. Точные команды сверить через `/grim help`.
- Плагины стенда, которые искажают результат (ElytraDisabled, WorldGuard, CombatLogger), на время теста
  отключить или обойти правом — иначе провал теста не равен провалу Grim.
- CoreProtect использовать как свидетеля: `/co inspect`, `/co lookup` подтверждают, что модуль реально ломал и ставил блоки.
