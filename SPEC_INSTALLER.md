# SPEC_INSTALLER.md — установщик MSI

> По прямой команде владельца, **после того как все функции сделаны**. Одна сессия, Opus, коммит и пуш после проверки, отчёт не больше одной страницы.
> Идёт до SPEC_RELEASE.md, чтобы чистка охватила файлы установщика.

## 1. Установщик (MSI, без консоли)
Цель: обычный Windows-установщик, который выглядит как нормальная программа.
- Формат: **MSI через WiX Toolset** (v4 или v5, по тому, что работает). Графический мастер (WiX UI), ни одного окна консоли, ни `cmd`, ни PowerShell в процессе установки.
- Что делает установка:
  1. Копирует `wisteria-*.jar` в `mods` выбранной папки Minecraft (по умолчанию `%APPDATA%\.minecraft`).
  2. Ставит профиль Fabric Loader для 26.2: записывает JSON версии в `versions/` (библиотеки скачает официальный лаунчер при первом запуске) и добавляет профиль в `launcher_profiles.json`. Перед изменением делается резервная копия файла. Если лаунчер не найден, установка копирует мод и показывает, что профиль нужно выбрать вручную (Fabric Loader уже стоит).
  3. Если нужна зависимость Fabric API, кладёт и её (проверить, требуется ли), с актуальной версией для 26.2.
- Мастер спрашивает имя папки данных (по умолчанию нейтральное, берётся из свойства сборки `dataDirName`, см. SPEC_RELEASE §7) и устанавливает мод под этим именем.
- Удаление: убирает только то, что поставил (мод и свой профиль), настройки и профили игрока в `.minecraft/wisteria` не трогает, если пользователь не отметил это галочкой.
- Сборка воспроизводима одной командой и через GitHub Actions (Windows runner), результат: `wisteria-<версия>-setup.msi`, контрольная сумма SHA-256 в описании релиза.
- Подпись: MSI собирается неподписанным, в отчёт: что нужно для подписи (сертификат подписи кода или Azure Trusted Signing) и где вставить шаг. Без подписи Windows SmartScreen покажет предупреждение, это ожидаемо и в README объясняется.
- В установщике и в самом клиенте нет окон консоли. Проверка: запуск игры и установки не создаёт `conhost`/`cmd`/`powershell` процессов (тест через список процессов).
- Файлы установщика не содержат личных данных и упоминаний инструментов разработки (чистка SPEC_RELEASE их охватывает).

## Готово, когда
`.msi` собирается одной командой, ставится и удаляется на чистом профиле Windows без консоли; проверка процессов зелёная; профиль Fabric появляется в лаунчере; описан шаг подписи; шлюз клиента зелёный.
