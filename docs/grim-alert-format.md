# Формат алертов Grim

Grim Lab (SPEC_AMENDMENT_2 §6) должен разбирать алерты Grim из чата. Формат строки зависит от версии и
настроек Grim, поэтому регулярные выражения пишутся только по реальным образцам со стенда.

**Образцов пока нет — разбор алертов не начат.**

## Что нужно от владельца

1. Версия: вывод `/grim version`.
2. Включить алерты (`/grim alerts`) и вызвать 3–5 разных срабатываний — например, простым Speed или Reach
   из любого клиента на тестовом аккаунте.
3. Скопировать строки чата как есть, без правок, в блок ниже. Нужны и обычные алерты, и `/grim verbose`, если он используется.
4. Если формат задан в конфиге Grim (секция сообщений), приложить эти строки тоже.

Ники и координаты можно заменить на выдуманные. Webhook-адреса и токены сюда не вставлять.

## Образцы

```
(пусто)
```

## Разбор

_Появится после образцов: поля (игрок, проверка, VL, подробности), регулярное выражение и набор тестовых строк._
